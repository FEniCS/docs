Detailed Description

Holder for the request of a non-blocking operation.

MPI_Request is a plain handle, so a class storing one bare cannot use a defaulted move: the moved-from object would be left naming the same request as the target. This holder transfers the request on move and leaves the source null, which keeps the owner's own move operations = default and correct as members are added.

Copying does not transfer a request in flight – the new request is null – so a copied owner does not wait on an operation it did not start. The owner's copy operations therefore stay usable.

Note
Nothing is released on destruction. A request is consumed by the MPI_Wait that completes it, which the owner is responsible for.

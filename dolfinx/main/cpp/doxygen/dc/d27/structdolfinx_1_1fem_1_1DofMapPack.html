Detailed Description

template<class D, class B, class E>
struct dolfinx::fem::DofMapPack< D, B, E >

Degree-of-freedom map data for one form argument, as passed to the assembly kernels.

A member rather than a tuple element, so that reading the block size cannot introduce a reference. A structured binding of a tuple-like type binds references, and a reference is not usable in a constant expression, silently costing the compile-time block size.

Template Parameters
DDofmap type, a rank-2 mdspan of const std::int32_t.
BBlock size type, int or std::integral_constant<int, N>.
EEntity index list type. Its shape differs between the cell, entity and facet kernels; see the DofMapPack* concepts below for what each requires.

Detailed Description

mdspan/mdarray namespace

Concept for a rank-2 mdspan-like type: exposes a value_type, has static rank() == 2, and supports two-index access and per-dimension extent queries. cv- and reference-qualifiers on T are stripped, so it can also constrain forwarding-reference parameters.
